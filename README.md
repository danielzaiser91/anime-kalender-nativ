# anime-kalender-nativ

Schlanker Zwilling von [anime-kalender.de](https://anime-kalender.de): Animation mit deutscher Synchronfassung, erschienen und
angekündigt, als Wochenübersicht. Nativ (HTML, CSS, ES-Module), ohne Abhängigkeiten, ohne Server, ohne Tracking.

Die Daten kommen stündlich aus dem öffentlichen Repo [anime-kalender-de](https://github.com/danielzaiser91/anime-kalender-de).
Newsletter, Push und Kalender-Abo mit Favoriten gibt es nur auf der Hauptseite.
